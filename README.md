## Nostra – Made for You, Every Day

**Live Website:** [ https://vishale2207-creator.github.io/nostra-made-for-you/]

Presenting my latest project — **Nostra**, a modern fashion shopping website designed to deliver a clean, interactive, and user-friendly browsing experience.

I built this project using HTML, CSS, and JavaScript, focusing on responsive layouts, interactive website elements, and smooth navigation.

### Key Features
- **Responsive Design:** Layout designed for different screen sizes.
- **Interactive Navigation:** Easy navigation between website sections.
- **Product Display:** Organized product sections with a clean layout.
- **JavaScript Functionality:** Interactive elements for a dynamic browsing experience.
- **Modern UI:** Consistent styling, typography, spacing, and layout.
- **Multi-Page Structure:** Separate pages for a more complete website experience.

### Technologies Used
- HTML5
- CSS3
- JavaScript
- Git & GitHub

Building Nostra helped me strengthen my front-end development skills and gain practical experience in website design, interactivity, and deployment.
